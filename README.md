# PawlyApp

PawlyApp is an Android application developed with **Kotlin** and **Jetpack Compose** as a final project for the **Software Engineering II** course.

The application allows users to browse information about different dog breeds through a simple and intuitive interface. Breed data is retrieved from a **GitHub Gist**, which is used as the project's data source.

## Features

- Login screen
- Navigation between multiple screens
- Bottom navigation bar
- MVVM architecture
- Dog breed information retrieval from a GitHub Gist
- Modern Android development with Jetpack Compose

## Technologies Used

- Kotlin
- Jetpack Compose
- Navigation Compose
- ViewModel
- GitHub Gist
- Android Studio

## Installation and Usage

1. Clone the repository:

```bash
git clone https://github.com/LeslieSc/PawlyApp
```

2. Open the project in Android Studio.

3. Sync the Gradle files.

4. Build and run the application on an Android emulator or physical device.

5. Log in and navigate through the application using the bottom navigation menu.
